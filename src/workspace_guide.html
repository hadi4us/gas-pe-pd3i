Cara menggunakan aplikasi PD3I per menu dan per role

Halaman ini menjelaskan alur kerja tiap menu, siapa yang boleh mengaksesnya, dan urutan kerja yang disarankan supaya petugas tidak salah tahap.

Prinsip umum

Urutan kerja aplikasi

  1. Input Kasus dipakai untuk membuat data awal kasus baru.
  2. Verifikasi EPID dipakai admin untuk review, koreksi, dan penetapan EPID.
  3. Hasil Sampel dipakai saat kasus memang menunggu hasil laboratorium.
  4. Status Pasien dipakai untuk memperbarui status akhir/perkembangan kasus.
  5. Cari / Edit dipakai untuk membuka record existing lintas diagnosis sesuai hak akses.
  6. Dashboard Statistik dipakai untuk melihat KPI, tren, dan distribusi kasus.
Role & akses

Siapa boleh mengerjakan apa

  • Admin: bisa input, cari/edit, verifikasi EPID, hasil sampel, update status, dan dashboard penuh.
  • Petugas puskesmas: bisa input kasus, cari/edit sesuai scope wilayah, hasil sampel sesuai pengampu, update status, dan lihat dashboard statistik.
  • Viewer: hanya lihat data dan statistik yang diizinkan, tanpa simpan perubahan.
  • Verifikasi EPID hanya muncul untuk akun admin.
  • Pembacaan data untuk akun puskesmas dibatasi oleh mapping REF_PENGAMPU.
Menu 1

Beranda KPI

  • Berisi KPI operasional yang scoped sesuai akun aktif.
  • Tampilkan total kasus dalam scope, breakdown diagnosis, workload aktif, dan antrian kerja prioritas.
  • Gunakan quick action untuk masuk cepat ke workspace kerja.
  • Beranda bukan daftar semua kasus wilayah, tetapi ringkasan kerja operasional.
Menu 2

Cari / Edit

  1. Buka menu Cari / Edit.
  2. Isi salah satu filter seperti Nomor EPID, ID Registrasi Kasus, Nama Pasien, atau Tanggal Lahir.
  3. Klik Cari Data Existing.
  4. Pilih hasil yang ingin dibuka.
  5. Workspace akan mengarahkan user ke mode kerja yang sesuai.

Pencarian bersifat lintas diagnosis, tetapi tetap dibatasi scope wilayah untuk akun puskesmas.

Menu 3

Input Kasus

  1. Pilih diagnosis di launcher input.
  2. Isi data pelapor, pasien, lalu data spesifik diagnosis.
  3. Pastikan field wajib dan validasi tanggal terisi benar.
  4. Klik Simpan Input Awal.
  5. Setelah tersimpan, record akan siap masuk ke tahap kerja berikutnya sesuai role.
Menu 4

Verifikasi EPID

  1. Menu ini hanya tersedia untuk admin.
  2. Buka antrian verifikasi atau cari record yang statusnya pending/revisi.
  3. Review data input awal secara menyeluruh.
  4. Tentukan status verifikasi: Terverifikasi atau Perlu Revisi.
  5. Jika terverifikasi, tetapkan atau koreksi Nomor EPID lalu simpan.
Menu 5

Hasil Sampel

  1. Buka menu Hasil Sampel.
  2. Gunakan filter antrian di atas untuk menyaring kasus menunggu hasil lab.
  3. Pilih salah satu kasus dari daftar antrian.
  4. Isi form hasil pemeriksaan laboratorium.
  5. Simpan. Jika hasil sudah final, kasus keluar dari antrian hasil sampel.
Menu 6

Status Pasien

  1. Buka menu Status Pasien.
  2. Filter antrian kasus yang siap update status.
  3. Buka kasus yang relevan.
  4. Isi status pasien/kasus sesuai perkembangan terakhir.
  5. Simpan agar riwayat status kasus terbarui.
Menu 7

Dashboard Statistik

  • Tersedia untuk admin, petugas, dan viewer sesuai blok yang diizinkan.
  • Gunakan untuk melihat KPI, tren kasus, distribusi wilayah, dan hotspot.
  • Blok yang khusus admin seperti antrian verifikasi admin tidak ditampilkan pada role non-admin.
  • Dashboard tetap mengikuti scope wilayah untuk akun puskesmas.
Tips kerja

Praktik yang disarankan

  • Gunakan Cari / Edit jika ingin membuka record existing lintas diagnosis.
  • Gunakan menu kerja spesifik (Hasil Sampel, Status) untuk menyelesaikan antrian lebih cepat.
  • Jangan gunakan Verifikasi EPID untuk petugas non-admin.
  • Jika data tidak muncul, cek dulu apakah kasus berada di wilayah kerja sesuai REF_PENGAMPU.
  • Untuk data lama/legacy, gunakan pencarian dengan Nomor EPID, ID Registrasi Kasus, atau Nama Pasien.
