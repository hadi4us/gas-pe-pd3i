Cara menggunakan aplikasi PD3I per menu dan per peran

Halaman ini menjelaskan alur kerja tiap menu, siapa yang boleh mengaksesnya, dan urutan kerja yang disarankan supaya petugas tidak salah tahap.

Prinsip umum

Urutan kerja aplikasi

  1. Input Kasus dipakai untuk membuat data awal kasus baru.
  2. Verifikasi EPID dipakai admin untuk peninjauan, koreksi, dan penetapan EPID.
  3. Hasil Pemeriksaan dipakai saat kasus memang menunggu hasil laboratorium.
  4. Status Pasien dipakai untuk memperbarui status akhir/perkembangan kasus.
  5. Daftar Kasus dipakai untuk membuka data yang sudah ada lintas diagnosis sesuai hak akses, termasuk edit dan hapus sesuai kewenangan.
  6. Dashboard Statistik dipakai untuk melihat indikator, tren, dan distribusi kasus.
Peran & akses

Siapa boleh mengerjakan apa

  • Admin: bisa input, list kasus/edit/hapus, verifikasi EPID, hasil pemeriksaan, pembaruan status, dan dashboard penuh.
  • Petugas puskesmas: bisa entri kasus, list kasus/edit sesuai cakupan wilayah, hasil pemeriksaan sesuai pengampu, pembaruan status, dan lihat dashboard statistik.
  • Viewer: hanya lihat data dan statistik yang diizinkan, tanpa simpan perubahan.
  • Verifikasi EPID hanya muncul untuk akun admin.
  • Pembacaan data untuk akun puskesmas dibatasi oleh mapping REF_PENGAMPU.
Menu 1

Beranda indikator

  • Berisi indikator operasional yang disesuaikan dengan akun aktif.
  • Menampilkan total kasus dalam cakupan, rincian diagnosis, beban kerja aktif, dan antrean kerja prioritas.
  • Gunakan aksi cepat untuk masuk ke menu kerja yang dibutuhkan.
  • Beranda bukan daftar semua kasus wilayah, tetapi ringkasan kerja operasional.
Menu 2

Daftar Kasus

  1. Buka menu Daftar Kasus.
  2. Isi kata kunci atau filter seperti diagnosis, kecamatan, kelurahan, status kasus, dan status verifikasi.
  3. Klik Terapkan Filter.
  4. Pilih tombol Edit untuk membuka data. Tombol Hapus tersedia untuk admin, serta pengguna berwenang pada data yang masih pending/belum diverifikasi.
  5. Menu kerja akan mengarahkan pengguna ke mode kerja yang sesuai.

Pencarian bersifat lintas diagnosis, tetapi tetap dibatasi cakupan wilayah untuk akun puskesmas.

Menu 3

Input Kasus

  1. Pilih diagnosis di launcher input.
  2. Isi data pelapor, pasien, lalu data spesifik diagnosis.
  3. Pastikan field wajib dan validasi tanggal terisi benar.
  4. Klik Simpan Input Awal.
  5. Setelah tersimpan, data siap masuk ke tahap kerja berikutnya sesuai peran.
Menu 4

Verifikasi EPID

  1. Menu ini hanya tersedia untuk admin.
  2. Buka antrian verifikasi atau cari data yang statusnya pending/revisi.
  3. Peninjauan data entri awal secara menyeluruh.
  4. Tentukan status verifikasi: Terverifikasi atau Perlu Revisi.
  5. Jika terverifikasi, tetapkan atau koreksi Nomor EPID lalu simpan.
Menu 5

Hasil Pemeriksaan

  1. Buka menu Hasil Pemeriksaan.
  2. Gunakan filter antrian di atas untuk menyaring kasus menunggu hasil lab.
  3. Pilih salah satu kasus dari daftar antrian.
  4. Isi formulir hasil pemeriksaan laboratorium.
  5. Simpan. Jika hasil sudah final, kasus keluar dari antrean hasil pemeriksaan.
Menu 6

Status Pasien

  1. Buka menu Status Pasien.
  2. Filter antrian kasus yang siap pembaruan status.
  3. Buka kasus yang relevan.
  4. Isi status pasien/kasus sesuai perkembangan terakhir.
  5. Simpan agar riwayat status kasus terbarui.
Menu 7

Dashboard Statistik

  • Tersedia untuk admin, petugas, dan viewer sesuai blok yang diizinkan.
  • Gunakan untuk melihat indikator, tren kasus, distribusi wilayah, dan hotspot.
  • Blok khusus admin, seperti antrean verifikasi admin, tidak ditampilkan pada peran non-admin.
  • Dashboard tetap mengikuti cakupan wilayah untuk akun puskesmas.
Tips kerja

Praktik yang disarankan

  • Gunakan Daftar Kasus jika ingin membuka data yang sudah ada lintas diagnosis.
  • Gunakan menu kerja spesifik (Hasil Pemeriksaan, Status) untuk menyelesaikan antrian lebih cepat.
  • Jangan gunakan Verifikasi EPID untuk petugas non-admin.
  • Jika data tidak muncul, cek dulu apakah kasus berada di wilayah kerja sesuai REF_PENGAMPU.
  • Untuk data lama/legacy, gunakan pencarian dengan Nomor EPID, ID Registrasi Kasus, atau Nama Pasien.
